## Host API for P5

`render-adoption/buildings/index.mjs` exports async `createBuildingLayer({scene,terrainSurface,world,invalidate,quality})`. Optional `manifest` and `loader` arguments allow host preloading/testing. Use the repository's bundled Three implementation; a supplied loader transfers ownership of each loaded GLTF to this layer.

The returned object has async `update(view, context)`, async `setQuality('normal'|'low')`, synchronous `status()`, detached `getPlacements()`, and idempotent synchronous `dispose()`. Await updates before consuming placements. There is no RAF, economic tick, storage write, hidden idle animation or network service. Loader completions use generation tokens; stale work cannot attach after a quality/revision change or disposal. Equal revision/LOD updates coalesce. Hidden context releases the active closure; the next visible update reloads it. A failed load selects host legacy rendering; change quality/view revision to retry.

Use the revision-1 read view. `identity` for homes is the **existing uint returned by visualIdentity(seed, originalHouse)**. HOME_IDS and its hash are imported unchanged. Never hash a reduced view object instead of the original saved entity. Yaw is Three Y rotation: local X/Z maps to saved X/Y with `[cos*x+sin*z, -sin*x+cos*z]`. Transform positions are centered game units. Asset scale is always 2.8; no scale-to-fit exists. `fixtures.mjs` supplies a detached, frozen example bridge, not a new saved schema or the application bridge. Its facility orientations match the application nearest-road/lane-facing rule, checked against facilityPlacement. Its fixture widths match current 34-unit main road shoulders and 5-unit local lanes. P5 must supply the current curved road alignments and actual displayed terrain resolution, not endpoint chords or the fixture terrain.

Context accepts:

- `cameraPositionGame: [x,y,z]` (or `camera.position`), centered game coordinates. Without a camera, all admitted entries use requested quality. `visible:false` pauses/hides/releases resources.
- `blockersWorldGame: [{key,polygon:[{x,y}]}]` for external exclusions, `legacyPlacements: [{key,polygonWorldGame}]` from existing legacy presentation, and `placementRevision` when those blockers change without a view revision. Roads/local lanes in the read view need explicit `width` and `points`; unavailable widths are not invented by the layer.

`getPlacements()` returns `{contractRevision,viewRevision,units,records}`. Admitted records include stable key/asset/variant, full or compact mode, actual fixed transform, level floor, seat/roof/stair/porch/full polygons in saved world-game and centered-metre coordinates, all source entrance/loading/stair corridors and actual approach, individual support contacts, and integral mesh exclusions. `retainedBoundaryFragments` identifies C4 decorative fence polygons without granting property rights. `integralExclusions` is the conservative normal/low union, stable across camera/quality changes. `renderedIntegralContacts` records the current seated derivative separately. Culled sites retain occupancy. P3 must consume the stable exclusions, not only rendered contacts. All metre heights are divided by 2.8 exactly once.

Fallback records name the asset/reason, set `hostRenderRequired:true`, and leave transform/floor null. They carry `legacyExclusionWorldGame` when supplied. **P5 must render the existing legacy path for every fallback key and suppress it for every admitted key**, including load/seating failures. P1 never draws a second family on an entity. Supply legacy footprints for fallback occupancy; absence is explicit rather than invented ownership. Sixth-home and no-parcel houses always stay legacy. Failed parcels remain the same saved entity at the same position.

`entityKeyForIntersection(hit)` resolves both ordinary source instancing and merged foundation face identities. P5 should use it when dispatching picks. `status()` exposes contract/source pins, requested quality, effective LOD counts, admitted/fallback keys and reasons, failures, pending loads, transfer/decoded-mip closure estimates, rendered geometry/texture estimates and triangle/batch counts. Readiness is local layer completion; `offlineInstalled:false` and pending device acceptance are explicit.

## Admission and terrain seating

Admission uses the all-quality rotated full bounds, not only a seat or four vertex tests. It checks concave parcel edges and holes, known neighboring envelopes, road right-of-way, all approach corridors, shoreline/interior samples, displayed terrain triangle vertices and analytic grade. It also rejects an approach crossing its own structure. Optional dressing is omitted and compact bounds retried before stable legacy fallback. Facilities without parcel fields use the existing buildingFootprint reservation in their supplied orientation. This is a visual fit check, not a new owned parcel or a changed gameplay validity rule.

Normal source vertices, materials, poses, layered roofs and flue geometry are retained. The normal/low/distance site envelope union prevents camera changes from replanning parcels. Civic merged geometry is partitioned by connected pieces into semantic tree, furniture, stage, fountain, planter and stall groups; roofs and their stalls share the same anchor datum. Furniture anchors use ground height, not seat height. Kit ground planting/fences/wagon and supported cargo share explicit seating anchors; elevated granary cargo stays at its floor. Surfaces are clipped against the host's displayed terrain triangles with original UV/channel interpolation and source paving/path offsets. Trees and furniture remain rigid. Individual feet extend below the level datum. Supplemental continuous skirts exist only under structural seats, are merged by material/chunk, and preserve per-face picking. Parks have no plot foundation; the granary's 1.35-m floor and open undercroft are never filled.

## Outputs, resources and distance policy

Run `node scripts/build-wv007-buildings.mjs`. The generator verifies the four frozen C4/D input hashes, copies explicit selected roots, partitions seating groups, removes unrelated resources, emits five self-contained GLBs and independently runs glTF validation. It copies the source licenses. It never imports private kits, authoring checkpoints or comparison bundles. Exact pins, output SHA-256, per-entry source-node/output mapping, triangle/primitive counts, image hashes/bytes/mips and error measurements are in `assets/wv/runtime-buildings-v1/manifest.json` and `docs/testing/wv007-p1/artifacts.json`.

Normal selects normal C4 geometry/materials. Low selects only low roots with base colors and no normal, metallic-roughness or occlusion images in its dependency closure. Normal and low bundles are not parsed together merely to select a root. A normal scene with distant entities can legitimately load normal plus distance bundles; status reports their summed decoded estimates. Switching entirely to low releases old normal resources. Embedded images have no remote dependencies. Bundles are selective by family/quality, not individual asset; loading one normal model still decodes the normal C4 library. This explicit tradeoff shares images/materials across settlement instances.

Distance switches at 280 game units with 24-unit hysteresis and culls beyond 1000; it uses a separate low-parent derivative with optional dressing/goods omitted. It never uses settlement count to change normal quality and retains layered roofs/flue. `error.normalReference` reports deterministic sampled nearest-structural-vertex RMS/max in both directions, **not surface Hausdorff or pixel error**; optional omissions are separate. Distance retains all remaining low-parent vertex positions (zero displacement). Side-by-side captures show requested quality versus distance. No provisional triangle guard has been relaxed; isolated 100-home measurements are reported in `benchmark.json`. They do not approve a phone profile.

The layer owns GLTF geometry/materials/textures/decoded images, its procedural geometry, batch buffers and foundation material. Clones borrow source resources. Batches dispose only instance buffers; the pool releases sources once, after batches are removed. Pending stale loads are disposed on completion. The host scene, world, terrain adapter, camera and renderer are borrowed and never disposed.

## D preview library

`createPreviewAssetLibrary({manifest?,loader?})` is async and returns `{list,load,status,dispose}`. Call `load({family:'D',id:'storehouse-l1'|'warehouse-l2'|genericPropId,quality:'normal'|'low'})`; all 20 D IDs at both qualities are listed explicitly. Each result supplies `{scene,metadata,previewOnly:true,ownership}`. Keys include family, ID and quality. Remove clones before library disposal. This adds no BUILDINGS entry, economy, stock, capacity or staffing assertion. D resources load only when this separate API is used.
