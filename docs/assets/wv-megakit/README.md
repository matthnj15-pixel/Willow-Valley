# Acquired MegaKit evidence

This directory contains research metadata, the attached art license, and rendered comparison images. **It does not contain the acquired archive, model geometry, textures, engine projects, or executable vendor tools.**

Read [the recommendation](../../design/WV-ART-004-megakit-audit.md) and [Codex handoff with common human-scale specifications](../../handoffs/WV-ART-004-megakit-codex.md).

| File | Meaning |
| --- | --- |
| `summary.json` | Exact archive identity, counts, categories, nested formats and aggregate geometry |
| `all-files.csv` | Every non-directory outer/nested file, its container, byte size and SHA-256. `modelContainer` flags file formats that may contain model data; it does not label every Unreal material `.uasset` as a separate model |
| `models.csv`, `models.json` | 304 canonical glTF visual modules: actual default-scene vertex bounds, triangle/primitive counts, materials, dependencies, sizes and hashes. Units are authoring units until deliberately calibrated |
| `godot-variants.json` | 305 outer Godot glTF variants, excluding collision-only geometry from measurements; the extra export is sample ground |
| `demo-assemblies.json` | Five named authored Godot demo groups with exact part paths/transforms; excludes whole-group village placement. C/C2 signatures match. These are source arrangements, not finished approved game assets |
| `shortlist.json` | 38 verified inputs and dependency hashes selected for proposed small-scale assemblies; not a runtime manifest |
| `textures.json` | All 100 outer PNG paths, dimensions, byte counts and hashes; RGBA8 estimates exclude mipmaps and block compression |
| `License_Source.txt` | Exact attached pack-specific CC0 notice, copied without line-ending changes |
| `license-findings.json` | Attached notice plus separately licensed Unity package notice and its metadata |
| `study-board.jpg` | Actual reconstructed sample arrangements, shown with 256-pixel inspection textures and original glTF materials. No custom engine shader or final palette |
| `audit-megakit.py` | Reproducible read-only ZIP metadata/geometry audit; requires Python and numpy; executes no vendor scripts |

## Reproduce

Keep the private original archive outside the Git checkout. Run:

```sh
python3 docs/assets/wv-megakit/audit-megakit.py \
  /private/path/MedievalVillageMegaKit-Source.zip \
  /temporary/path/megakit-audit
```

Verify archive SHA-256 `5e60888e2babe418a4618e7815539d9b1b2c3b24c1db2b22cd7a2a7f66140732` before comparing outputs. The output directory receives metadata only. ZIP dependencies are read in place, including nested engine archives. The script walks visual glTF default scenes, applies node transforms, reads actual POSITION buffers including strides, and counts triangle primitives. It filters Godot `-convcolonly` meshes. It does not use triangle counts from marketing, trust a filename as a complete building, or import engine tooling. This script is scoped to the verified archive's layout and ordinary triangle/float-position glTF exports, not a general untrusted ZIP extractor or generic glTF implementation.

The study board was produced separately with the repository's bundled Three.js GLTFLoader. Source group matrices were applied in column-major order, matrix world updates forced before measuring, and full-group floor/centering applied only for display. GPU bounds matched CPU measurements to 0.00001 authoring units. Temporary downscaled textures reduced inspection memory; exported source measurements and hashes always refer to the untouched archive. No image-generation model supplied or modified the source geometry.

The shortlist, narrative, and visual board are curated recommendations and are not regenerated by the audit script. For a new revision, regenerate metadata in a temporary directory, compare it, and repeat licensing and visual review. Do not overwrite the evidence for this hash silently.
