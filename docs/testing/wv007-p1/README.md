# P1 verification evidence

All five derived GLBs validate with zero errors and zero warnings, both in the generator and independently in the unit suite. Two successive builds match all output SHA-256 hashes byte-for-byte, including the manifest and license copies. `artifacts.json` records the source and output pins and per-entry geometry/error measurements.

Focused tests cover unchanged identity selection, five work roles/eight civic variants, fixed rotated fits, concave notches/holes/tight parcels, neighbor and approach collision, shore corners, tall roof bounds, unsafe displayed/analytic grades, granary floor/individual feet, exact low resource closure, hierarchy matrices/picking, immutable actual founding and serialized grown-save fixtures, normal at 100 homes, asynchronous quality coalescing, hidden/resume, load failure, stale completion/disposal and D family/ID/quality keys.

Browser tests load the real selective GLBs, visit every civic/workplace entry, inspect furniture datums and sloped granary feet, verify quality/resource replacement and stable exclusions, render a detached actual generated-world founding snapshot, and record an isolated 100-C4-home normal/low/distance benchmark. The 100-home case is synthetic regression coverage; actual-state cases are separately identified. No player data or saved storage is changed.
